Setting up Chrome Prompt API

This wiki uses Gemini Nano — Chrome's built-in local LLM. No API keys. No data sent to servers. Everything runs on your device.

Step 1: Open Chrome flags:

chrome://flags/#prompt-api-for-gemini-nano

Step 2: Set to Enabled (or Enabled multilingual)

Step 3: Restart Chrome completely.

Step 4: Model downloads automatically on first use (~few hundred MB). Check download progress at:

chrome://on-device-internals

Requirements: Chrome on Windows 10/11 or macOS 13+. GPU with >4 GB VRAM or 16 GB RAM.
